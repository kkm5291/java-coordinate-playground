## 기능 요구사항 (선)

- 좌표 정보 입력 (좌표 정보는 **괄호**로 둘러쌓여 있으며 쉼표로 x , y 구분)
  - 좌표는 각 최대 24까지만 입력 가능
  - 입력 범위 초과할 경우 에러 문구 출력하고 다시 입력 받음
- 좌표값 입력 되면 해당 좌표에 특수문자 표시
- 좌표값을 두 개 입력한 경우, 두 점을 잇는 직선으로 가정함. 좌표값과 좌표값 사이는 '-' 문자로 구분함
- 직선이라면 두 점 사이 거리를 계산해서 출력한다.

### 테스트가 쉬울 법 한 로직 선별하기
1. 좌표 사이값 구하기 []
    - 좌표 사이값 구하는 공식은 Line 클래스에서 진행
2. 좌표 정보 입력부분 
   - 좌표 값은 각 최대 24까지, 입력 범위 초과시 예외 발생 []
3. 괄호로 둘러쌓여야 함 (InputUtils에서 구현) []
  - 좌표값 사이는 - 로 구분되어야 함 []

### InputView

- 입력값의 pattern 이 올바른 가?
- 입력값이 empty 인가?

### Point

- x,y 값이 범위를 초과하는 가?

### Square

- 좌표값을 두 개 입력한 경우, 두 점을 있는 직선으로 가정한다. 좌표값과 좌표값 사이는 '-' 문자로 구분한다.
- 좌표값을 네 개 입력한 경우, 네 점을 연결하는 사각형으로 가정한다.
- 네 점이 뒤틀어진 사다리꼴이나 마름모는 제외하고 직사각형만 허용하도록 검사한다.
- 사각형인 경우 사각형의 넓이를 계산해서 출력한다.
